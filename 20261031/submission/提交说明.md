## 启动

席位、令牌、网关、ROS 网络均按主办方现场通知通过环境变量注入：

```bash
docker run --rm --network host \
  -e RMTC_SEAT=A \
  -e RMTC_TEAM_TOKEN="<本场席位令牌>" \
  -e RMTC_AI_URL="<本场统一 LLM 网关完整 completions 地址>" \
  -e ROS_DOMAIN_ID=27 \
  -e ROS_LOCALHOST_ONLY=0 \
  -e RMW_IMPLEMENTATION=rmw_fastrtps_cpp \
  rmtc-team:20261029
```

- 未提供 `RMTC_TEAM_TOKEN` 时程序打印提示并以退出码 2 终止，不会空跑。
- 镜像内不含任何令牌、密钥或练习场次数据。
- `decision_config.json` 已打包在镜像内，仅含 `decision_type`（`collect` / `survive`），
  运行中每 20 Tick 重新读取，暂停期间修改、恢复后生效。
